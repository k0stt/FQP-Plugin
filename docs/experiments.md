## Этап 1a (E0): Baseline реконструкция RAVE (предобученная модель `musicnet.ts`)

**Модель:** `models/musicnet.ts` (sha256: `5228bc514c0a38280b774fd5a75ba5883e40013419a5acb0840ebd56d36e855b`)
- **Оговорка к архивным результатам:** текущие `outputs/e0/*/report.json` не подтверждают единую таблицу ниже: `juchki` и `cheerful` получены с `models/lofi_v2.ts` (checkpoint/источник обучения не идентифицирован); `osel` и `hip-hop-chant` — с `musicnet.ts`. RTF, качество и group delay в архивных отчётах не совпадают с некоторыми строками таблицы. Поэтому таблица сохраняется как историческая запись, **не** как проверенное сопоставимое измерение одной модели. Новые сопоставления см. ниже (stage1b); не объединять модели/датасеты без фиксации SHA256.
- sr=44100, моно, PQMF 16 бандов, латент 16 каналов (из 128 PCA), сжатие ≈2048×
- Энкодер: VariationalEncoder → VAE постериор (randn сэмплирование)
- Декодер: GeneratorV2 + PQMF inverse

**Протокол воспроизводимости:** `encode_deterministic()` использует posterior **mean** (без randn) → полностью детерминирован; штатный `model.encode()` сэмплирует постериор (aten::randn) → нужны свежий процесс + фиксированный seed.

**Окружение:** Windows 10, Python 3.10.11, torch 2.6.0+cu124, CUDA 12.4, RTX 4060 Laptop 8 ГБ

**RTF на GPU:** 0.018–0.022 (≈45–55× realtime) на 30-с фрагментах; на коротких (9 с) выше из-за накладных расходов загрузки модели.

**Задержка (group delay, кросс-корреляция вход/выход на белом шуме):** ~241 мс (10637 сэмплов) — соответствует теории: PQMF analysis + encoder receptive field + decoder + PQMF synthesis. Импульсный замер (encode mean) даёт ~600 мс (пик несовпадает с группой из-за формы импульсного ответа).

**Качество реконструкции (SC / LSD):**
- SC (spectral convergence) ~0.95–1.0 — энергия спектра совпадает, но фаза/структура теряется (ожидаемо для VAE без фазовой потерь).
- LSD (log spectral distance) 0.34–0.77 — лог-спектры отличаются; низкие частоты лучше, высокие — хуже (PQMF boundary artifacts).
- Выход тише входа (RMS out ≈ 0.05 vs in 0.04–0.06) — модель не сохраняет громкость (нет loudness conditioning).

**Целостность:** NaN/Inf = 0, клиппинг = 0, внутренние разрывы тишины ≤2 на файл (границы VAE-декодера), начало/конец без тишины.

### Выводы E0

1. **Офлайн-инференс быстрый (RTF ≪ 1)** в данном запуске; здесь RTF = измеренное время encode + decode / длительность входа. Замер не включает загрузку модели, декодирование файла и запись результата; не проверяет дедлайны аудиоблоков и **не доказывает** потоковую пригодность. Для SuperCollider отдельно измерить полную цепь (включая передачу данных, грануляцию и пространственное декодирование), буферизацию, задержку и xRuns.
2. **Задержка ~240–310 мс** — для плагина потребуется компенсация (report latency to host) или стриминговый режим RAVE (streaming export).
3. **Качество реконструкции «сырое»**: SC≈1, LSD≈0.4–0.8 — модель обучена на MusicNet (классика/пиано), на lo-fi даёт заметную потерю тембра и высоких частот. Для этапов E1–E3 (грануляция) это **базовая линия**, артефакты грануляции будут измеряться *над* этим фоном.
4. **Громкость не сохраняется** — перед грануляцией вход будет peak-нормироваться к 0.9, выход — gain-matched к входу.
5. **Детерминизм обеспечен** через posterior mean; для сравнения методов (волна vs латент) этого достаточно.

**Прослушивание пользователя (после 20k):** слышны щелчки и сильное изменение тембра, вплоть до других нот — модель **не прошла** субъективную проверку.
