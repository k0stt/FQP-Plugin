**Интеграционная ветка:** `main` (локально на один коммит `3c321ed` впереди `origin/main`); рабочая ветка: `fix/stage1b-training-smoke`. Не выполнять push без разрешения.

## Этапы и зависимости

1. **1b — в работе:** проверить права/происхождение данных, входы, конфигурацию; smoke-run + загрузка checkpoint + реконструкция; обучить модель, оценить её на отложенных данных (SC/LSD, целостность, фактические sr/сжатие/латенты/задержка). Завершение только после проверки итоговой модели.
2. **2:** E1/E2: два гранулятора и тесты границ/стыков/уровня/детерминизма; E3: одинаковые материалы и параметры, честное сравнение, RTF = время всей обработки / длительность выхода (значение < 1 означает быстрее реального времени). Для потоковой пригодности отдельно проверять нагрузку и задержку по блокам.
3. **3–4:** FOA с определёнными каналами и нормализацией, бинуральное декодирование и проверки движения; интегрировать и прослушать интерактивный прототип в SuperCollider, измерить полную нагрузку и задержку.
4. **5+:** VST3 только после проверенного прототипа; сборка, загрузка, звук и регрессии.
